# Discord Bot - Watermark Management Bot

## 概要

このDiscord Botは、Discordチャンネルごとにウォーターマーク画像を設定し、そのチャンネルへ投稿された画像に透かしを自動適用するBotです。

現在の運用方針は、Discordの正式なスラッシュコマンドを主体にします。

---

## 主な機能

1. チャンネルごとのウォーターマーク設定
2. 投稿画像への自動透かし合成
3. チャンネルごとの透過度設定
4. 現在設定されている透かし画像の確認
5. チャンネル設定の削除

---

## コマンド一覧

### `/wm set`

現在のチャンネルに透かし画像を設定します。

#### オプション

| オプション       | 必須 | 内容           |
| ----------- | -: | ------------ |
| `watermark` | 必須 | 透かしとして使用する画像 |
| `opacity`   | 任意 | 透過度。1〜100の整数 |

#### 備考

* 同じチャンネルで再設定した場合、古い透かし画像は削除されます。
* `opacity` を省略した場合、既存設定の透過度、または初期値 `15%` を使用します。

---

### `/wm check`

現在のチャンネルの透かし設定を確認します。

表示内容：

* 設定済みの透かし画像
* 元ファイル名
* 現在の透過度

---

### `/wm opacity`

現在のチャンネルの透過度を変更します。

#### オプション

| オプション     | 必須 | 内容           |
| --------- | -: | ------------ |
| `opacity` | 必須 | 透過度。1〜100の整数 |

---

### `/wm clear`

現在のチャンネルの透かし設定を削除します。

削除対象：

* チャンネル設定
* 保存済みの透かし画像ファイル

---

### `/wm help`

Botの使い方を表示します。

---

## 自動動作

透かし画像が設定されているチャンネルに画像が投稿されると、Botが自動で透かし入り画像を返信します。

透かし画像が設定されていないチャンネルでは何もしません。

---

## データ保存仕様

初期設定では、設定データは `data/src` 以下に保存されます。

```text
data/src/{guild_id}/settings.json
data/src/{guild_id}/{channel_id}/{watermark_file}
```

`settings.json` の基本構造：

```json
{
  "channels": {
    "123456789012345678": {
      "active_watermark": "data/src/111111111111111111/123456789012345678/xxxxxxxx.png",
      "watermark_original_filename": "watermark.png",
      "transparency": 15
    }
  }
}
```

---

## 環境変数

`.env` に以下を設定します。

```env
DISCORD_TOKEN=your_discord_bot_token
BASE_DIR=data/src
```

| 変数              | 必須 | 内容                               |
| --------------- | -: | -------------------------------- |
| `DISCORD_TOKEN` | 必須 | Discord Botのトークン                 |
| `BASE_DIR`      | 任意 | 設定データと透かし画像の保存先。未指定時は `data/src` |

## 開発メモ

### 現在の方針

* prefix commandは原則廃止し、スラッシュコマンド主体にする
* チャンネルごとに透かし設定を分離する
* 既存の `data/src` 配下のデータ構造は維持する
* 画像処理関数は出力ファイルパスを返す
* 自動処理は、透かし設定済みチャンネルへの画像投稿時のみ動作する

### 今後の候補

* `/wm tos` の追加
* 多言語対応
* GIF/APNGの品質改善
* Bot管理者向けコマンド
* エラー画像の保存方針整理
* 古い一時ファイルの定期削除

---

## 既知の注意点

* Botが画像投稿を検知するため、Discord Developer Portal側で必要なIntent設定が必要です。
* 透かし設定後は、そのチャンネルへ投稿された画像が自動加工されます。
* Bot専用チャンネルを作ることを推奨します。
